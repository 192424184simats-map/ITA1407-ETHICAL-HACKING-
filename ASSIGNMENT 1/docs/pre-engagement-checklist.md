# Pre-Engagement Checklist

- [ ] Request has a clear purpose and named requester.
- [ ] System owner and governance approval recorded.
- [ ] Signed authorization verified; Engagement ID issued.
- [ ] Assessor identity and (if external) vetting/NDA completed.
- [ ] Exact asset IDs listed and validated against inventory.
- [ ] Out-of-scope assets and prohibited methods communicated.
- [ ] RoE version signed and testing window agreed.
- [ ] Legal and privacy review completed.
- [ ] DPO approval recorded where personal data may be involved.
- [ ] Emergency-stop contact and escalation path tested.
- [ ] Isolated host-only lab configured and route/adapter checks recorded.
- [ ] Test accounts and synthetic data prepared.
- [ ] Evidence storage, access controls and retention period agreed.
- [ ] Finding and disclosure templates prepared.
- [ ] All team members briefed on stop-and-report rules.

**Gate:** Every mandatory item must be complete. Any unchecked mandatory item means HOLD — do not start.
